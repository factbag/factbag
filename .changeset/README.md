# Changesets

Add a changeset for every user-visible change:

```sh
pnpm changeset
```

`factbag`, `@factbag/jev`, `@factbag/clef`, and `@factbag/openai` are published and always released together at the same version. The other component packages, examples, and tooling are private and are not versioned. See [`RELEASING.md`](../RELEASING.md) for release procedures.
